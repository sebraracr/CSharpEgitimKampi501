Yazılım alanında kendimi geliştirmeye devam ederken, C# ve .NET Core kullanarak Dapper ORM ile bir Ürün Yönetim Sistemi projesi üzerinde çalışıyorum.

💻 **Projemde kullandığım teknolojiler:**
🔹 C#
🔹 .NET Core
🔹 Dapper ORM
🔹 SQL Server
🔹 Windows Forms

📌 **Proje kapsamında geliştirdiğim özellikler:**
✅ Ürünleri listeleme, ekleme, silme ve güncelleme
✅ Kategorilere göre ürün filtreleme
✅ Toplam ürün sayısını hesaplama
✅ Belirli bir kategorideki en pahalı ürünü bulma
✅ Kategori sayısını görüntüleme

Bu proje sayesinde veritabanı işlemleri, SQL sorguları ve uygulama geliştirme konularındaki bilgilerimi pekiştirirken, teorik bilgilerimi pratiğe dönüştürme fırsatı buluyorum.

Yazılım yolculuğumda öğrenmeye, üretmeye ve kendimi geliştirmeye devam ediyorum. 🚀
